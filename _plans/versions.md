## Kafka choice against Strimzi

The latest Strimzi release is 1.3.1 (2026-11-04). Its kafka-versions.yaml lists 4.2.0, 4.2.1, 4.2.2, 4.3.0, 4.3.1 and 4.3.2 as supported, with 4.3.2 as the default. Apache Kafka 4.4.0 is on Maven Central but is not in that list, so it is not used. The book pins Kafka 4.3.2 everywhere (the docker.io/apache/kafka broker in compose, the Kafka Dev Services image, and the Strimzi Kafka resource at r11), which is the newest version the latest Strimzi supports. The Debezium Connect image bundles Kafka 4.3.1 and the Quarkus platform brings kafka-clients 4.2.1; both are the same major line as the 4.3.2 broker and are not overridden.

### Tool syntax in apache/kafka:4.3.2

Tools are in `/opt/kafka/bin/` (checked with `ls`, then each `--help`); the container was removed on exit.

- `kafka-transactions.sh` is present. Usage: `kafka-transactions.sh [-h] [-v] [--command-config FILE] --bootstrap-server host:port COMMAND ...`. Commands: `list`, `describe` (an active transactional id), `describe-producers` (a topic partition), `abort` (a hanging transaction, needs administrative privileges), `find-hanging`, `forceTerminateTransaction` (on a transactionalId). KIP-664 (Adopted) documents the tool and its `find-hanging` and `abort --topic --partition --start-offset` forms.
- Console producer headers: `--reader-property parse.headers=true`. Defaults: `parse.key=false`, `parse.headers=false`, `key.separator=\t`, `headers.delimiter=\t`, `headers.separator=,`, `headers.key.separator=:`, `null.marker`, `ignore.error=false`. With `parse.headers=true` the input line is `h1:v1,h2:v2<TAB>value`; with `parse.key=true` as well it is `h1:v1,h2:v2<TAB>key<TAB>value`. (`--property` is shown as deprecated in favour of `--reader-property`.) Also `--reader-config` takes a properties file.
- Console consumer: `--isolation-level read_committed` (the help reads "Set to read_committed in order to filter out transactional messages which are not committed", default `read_uncommitted`) and `--formatter-property print.headers=true` (also `print.key`, `print.offset`, `print.partition`, `print.timestamp`, `print.epoch`).
