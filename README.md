# Event-Driven Patterns with Quarkus and Camel

A chaptered tutorial on event-driven patterns built on Quarkus, Apache Camel and Kafka:
event notification, event-carried state transfer, the transactional outbox, Debezium,
idempotent consumers, exactly-once, event sourcing, CQRS, schema evolution, stream
processing, sagas, observability with OpenTelemetry and LGTM, and Kafka on Kubernetes
with Strimzi.

Work in progress. Site: https://patterncatalyst.github.io/event-driven-patterns-with-quarkus-and-camel/
