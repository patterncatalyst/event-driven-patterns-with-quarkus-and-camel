Examples

One runnable project per pattern.

Every example is a Quarkus application with Camel routes, its own compose file, a Containerfile on UBI 10 and a verify.sh that proves the behaviour against the real stack. Start the stack from the repository root and run an example from its directory. 

./scripts/setup-stack.sh up
cd examples/00-stack-check
./verify.sh
